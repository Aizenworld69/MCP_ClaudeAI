# 🚀 MCP_ClaudeAI - Tổng Hợp MCP Servers & Extension Bundles (.mcpb)

---

## ⚡ Hướng Dẫn Sử Dụng Nhanh (Dành Cho Extension `.mcpb`)

1. Tải về file `.mcpb` của MCP Server bạn muốn dùng từ repository này.
2. Mở **Claude Desktop** hoặc **Antigravity IDE** ➔ Mở **Settings** ➔ **Extensions**.
3. Kéo thả file `.mcpb` vào ứng dụng.
4. Điền các mã Token/Keys cần thiết theo tài liệu hướng dẫn tương ứng ➔ Bấm **Save** là hoàn tất!
